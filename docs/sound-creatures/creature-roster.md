# おとのいきもの — キャラクター設定

これは実装IDを固定したまま、各発見をどのような生き物として表現するかを記録する
資料である。2026-08-04に全8体の画像と設定が人手承認された。名前はUIへ組み込む
段階まで仮称として扱う。

| DiscoveryId         | 仮称       | 音から受け取る性格               | シルエットの核                  | 動きの核                     |
| ------------------- | ---------- | -------------------------------- | ------------------------------- | ---------------------------- |
| `interval_third`    | ミッツ     | 少し離れた音と一緒に歌うのが好き | 離れた2つの耳と、ひとつの丸い体 | 2つの耳が交互に光って重なる  |
| `open_fifth`        | ノビーン   | 広い場所でのびのび鳴く           | 低く横にのびる橋形の音のひれ    | 左右のひれを広げて安定する   |
| `close_tension`     | ブルリ     | 近すぎる音にびっくりして震える   | 中央に近く並ぶ2本の音のつの     | つのから体へ細かな波が走る   |
| `stepwise_run`      | トコトコ   | 隣の音へ順番に歩く探検家         | 斜めに続く4段の体と4本の短い足  | 4本の足で順番に上下へ進む    |
| `call_and_response` | ヨビコタ   | 呼びかけを見つけると返事をする   | 上下で向き合う2つの声の端       | 3つの印が上から下へ応える    |
| `rest_then_burst`   | タメポン   | 静かに待ってから勢いよく飛び出す | 3段のひだと上へ開く3つの音の芽  | ひだを縮めてから芽が弾む     |
| `rhythm_loop`       | グルタン   | 同じ足取りを何度も楽しむ         | 中央に大きな穴がある丸四角の輪  | 左右の同じ2つの印が順に光る  |
| `sustain_contrast`  | ノビチョコ | 長い声と短い声を使い分ける       | 一本の長い声の尾と2本の短い足   | 尾を伸ばしてから足が順に弾む |

## 個体別設計

ここを個体固有の設定の正本とする。共通する線、顔、質感、画像仕様は
[`style-guide.md`](./style-guide.md) に置き、重複して記載しない。

### `interval_third` — ミッツ

| 項目           | 内容                                                                |
| -------------- | ------------------------------------------------------------------- |
| 仮称           | ミッツ / Mitts                                                      |
| 性格           | 少し離れた音と一緒に歌い、2つの響きを体全体で面白がる               |
| 音とのつながり | 左右の耳が2つの音を、左の3節と右の4節が3度を作る3半音・4半音を表す  |
| シルエット     | 縦長の丸い体、左右で節の数が異なる2つの大きな耳、その間の深い谷     |
| 主色           | ラベンダーパープル、ウォームコーラル、クリーム、濃いプラム          |
| 初回の動き     | 左右の耳が別々に反応してから同時に開き、体が少しだけ上へ弾む        |
| 再発見の動き   | 左右の耳が1回ずつ動いたあと、同時に小さく光る。再生や編集は止めない |
| alt文案        | 紫の丸い体と、左右で節の数が異なる珊瑚色の大きな耳を持つ、ミッツ    |
| アセット       | `public/creatures/interval_third/portrait.png`                      |

耳だけで音を聞くのではなく、2つの耳から入った音を丸い体全体で受け止める。
「音楽を知っている先生」ではなく、子どもと一緒に音を面白がる存在として描く。

### `open_fifth` — ノビーン

| 項目           | 内容                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 仮称           | ノビーン / Nobeen                                                     |
| 性格           | 広い場所でのびのび鳴く、落ち着いた聞き手                              |
| 音とのつながり | 遠く離れた左右のひれが、完全5度やオクターブの広く安定した響きを支える |
| シルエット     | 低い中央部から、丸い2本の音のひれが左右へ長くのびる橋形               |
| 主色           | コーンフラワーブルー、サニーイエロー、クリーム、濃いプラム            |
| 初回の動き     | 縮めた左右のひれをゆっくり広げ、中央の体が安定して止まる              |
| 再発見の動き   | 左右の先端まで1本の波が走り、中央へ戻る                               |
| alt文案        | 青い体から黄色い音のひれを左右へ大きく広げた、ノビーン                |
| アセット       | `public/creatures/open_fifth/portrait.png`                            |

ミッツの縦長な耳と重ならないよう、外周の価値を横幅に置く。鳥・翼・手ではなく、
体から連続した「音のひれ」として描き、遠い2音がひとつの体を支える形にする。

### `close_tension` — ブルリ

| 項目           | 内容                                                                |
| -------------- | ------------------------------------------------------------------- |
| 仮称           | ブルリ / Bururi                                                     |
| 性格           | 近すぎる音にびっくりして、もう一度聞きたがる好奇心旺盛な子          |
| 音とのつながり | 近く並ぶ2本の音のつのが隣り合う半音を、体側の波形が響きの震えを表す |
| シルエット     | 丸みのある四角い体、中央に近く並ぶ2本の短い音のつの、左右の波形     |
| 主色           | ラズベリーレッド、淡いシアン、クリーム、濃いプラム                  |
| 初回の動き     | 2本のつのが近づいて震え、その波が左右の体側を下へ走る               |
| 再発見の動き   | 2本のつのが一度だけ小さく震える。再生や編集は止めない               |
| alt文案        | 赤い丸四角の体に、近く並ぶ水色の音のつのと波打つ体側を持つ、ブルリ  |
| アセット       | `public/creatures/close_tension/portrait.png`                       |

怖さや攻撃性ではなく、「いつもと違う響きに気づいた驚き」と好奇心を表情に置く。
ミッツの縦長な羽根状の耳、ノビーンの横長な音のひれとは異なり、中央へ集まる形と
波打つ外周を輪郭の価値にする。

### `stepwise_run` — トコトコ

| 項目           | 内容                                                            |
| -------------- | --------------------------------------------------------------- |
| 仮称           | トコトコ / Tokotoko                                             |
| 性格           | 隣の音へ一歩ずつ進み、次の場所を見つけるのが好きな探検家        |
| 音とのつながり | 同じ向きへ進む4音を、左下から右上へ連なる4段の体と4本の足で表す |
| シルエット     | 4つの丸い段が斜めに連続し、その下に4本の短い足が並ぶ階段形      |
| 主色           | リーフグリーン、タンジェリンオレンジ、クリーム、濃いプラム      |
| 初回の動き     | 4つの足裏が進行方向へ順番に光り、体の4段が一段ずつ小さく弾む    |
| 再発見の動き   | 4本の足が進行方向へ一度ずつ軽く踏む。再生や編集は止めない       |
| alt文案        | 緑の4段の体とオレンジ色の4本の足で斜め上へ歩く、トコトコ        |
| アセット       | `public/creatures/stepwise_run/portrait.png`                    |

独立した階段や鍵盤を持たせず、生き物自身の連続した外周を4段にする。
上行形では左下から右上、下行形では反対向きに動きを流し、どちらも正しい発見として扱う。

### `call_and_response` — ヨビコタ

| 項目           | 内容                                                                        |
| -------------- | --------------------------------------------------------------------------- |
| 仮称           | ヨビコタ / Yobikota                                                         |
| 性格           | 呼びかけを聞き逃さず、少し間をあけて同じ調子で返事をする聞き上手            |
| 音とのつながり | 上下にずれた2つの声の端と同じ3つの印が、違う高さで繰り返す3音の形を表す     |
| シルエット     | 上の声と下の声が中央で一続きになり、内側に2つの大きなくびれを持つ折り返し形 |
| 主色           | アプリコットオレンジ、淡いアクア、クリーム、濃いプラム                      |
| 初回の動き     | 上の3つの印が順番に光り、短い間のあと、下の3つの印が同じ順番で光る          |
| 再発見の動き   | 上の口が一度開き、下の顔が小さく返事をする。再生や編集は止めない            |
| alt文案        | 上下で向き合う2つの顔と、同じ3つずつの水色の印を持つオレンジ色のヨビコタ    |
| アセット       | `public/creatures/call_and_response/portrait.png`                           |

二体組や二つ首の動物にはせず、上の呼びかけと下の返事を一続きの身体にする。
中央のくびれを「少し間をあける」時間として残し、同じ3音が別の高さから返る構造を
説明より先に見た目と動きで伝える。

### `rest_then_burst` — タメポン

| 項目           | 内容                                                                      |
| -------------- | ------------------------------------------------------------------------- |
| 仮称           | タメポン / Tamepon                                                        |
| 性格           | 静かな時間をじっと味わい、次の音が来ると喜んで飛び出す                    |
| 音とのつながり | 下の3段のひだが静かな1拍で力をため、上の3つの音の芽が次の音の集まりを表す |
| シルエット     | 横に重なる3段の丸いひだと、中央から上へ大きく開く3つの丸い芽              |
| 主色           | 深いターコイズブルー、やわらかなラベンダー、クリーム、濃いプラム          |
| 初回の動き     | 静かな1拍で3段のひだが縮み、次の1拍で上の3つの芽が順に伸びて弾む          |
| 再発見の動き   | ひだが一度だけ小さく縮み、3つの芽が軽く弾む。再生や編集は止めない         |
| alt文案        | 青い3段の体から紫の3つの丸い音の芽を飛び出させた、タメポン                |
| アセット       | `public/creatures/rest_then_burst/portrait.png`                           |

上の芽は花、王冠、手ではなく、圧縮された身体から連続して現れる太い音の部位とする。
「静かな時間は何もない」のではなく、その後を強く感じさせるための時間であることを、
縮む動きから弾む動きへの変化で伝える。

### `rhythm_loop` — グルタン

| 項目           | 内容                                                                            |
| -------------- | ------------------------------------------------------------------------------- |
| 仮称           | グルタン / Gurutan                                                              |
| 性格           | 同じ足取りを見つけると、うれしくなって何周でも楽しむ                            |
| 音とのつながり | 閉じた輪がリズムの戻りを、左右で同じ2つの印が次の拍でも同じ並びになることを表す |
| シルエット     | 中央に大きな穴がある丸四角の太い輪と、その下につながる2本の小さな足             |
| 主色           | サニーレモンイエロー、ベリーピンク、クリーム、濃いプラム                        |
| 初回の動き     | 左の2つの印が順に光り、次に右の2つが同じ順番で光って、一周の動きを作る          |
| 再発見の動き   | 4つの印を一度だけ追いかけるように光らせる。再生や編集は止めない                 |
| alt文案        | 大きな穴のある黄色い輪の体に、左右同じ並びのピンク色の印を持つ、グルタン        |
| アセット       | `public/creatures/rhythm_loop/portrait.png`                                     |

ドーナツ、車輪、時計などの道具にはせず、表情と足を持つ一続きの「生きた輪」として
描く。中央の穴には背景がそのまま見え、96pxでも閉じた輪であることを失わない。
左右の印は大きさと間隔をそろえ、1拍目と2拍目のタイミングと長さが同じであることを、
説明より先に身体から読み取れるようにする。

### `sustain_contrast` — ノビチョコ

| 項目           | 内容                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 仮称           | ノビチョコ / Nobichoko                                                         |
| 性格           | ひとつの声をゆっくり伸ばしたあと、軽い足取りで二歩進む                         |
| 音とのつながり | 左へ長く続く声の尾が1拍以上の長音を、その直後の2本の短い足が1マスの音2つを表す |
| シルエット     | 左へ極端に長い一続きの尾と、右端の丸い体、その下につながる2本の短い足          |
| 主色           | ココアブラウン、やわらかなローズコーラル、パウダースカイブルー、濃いプラム     |
| 初回の動き     | 声の尾を1拍かけて左へ伸ばし、止まった直後に2本の足が順番に一度ずつ弾む         |
| 再発見の動き   | 尾が一度ゆっくり波打ち、2本の足が小さく順に弾む。再生や編集は止めない          |
| alt文案        | 左へ長く伸びる桃色の声の尾と、2本の短い水色の足を持つ茶色のノビチョコ          |
| アセット       | `public/creatures/sustain_contrast/portrait.png`                               |

名前からチョコレートや菓子を描かず、音の長さを比べられる一体の身体として扱う。
左から右へ読むと、広く長い一続きの形のあとに、小さな足が2つだけ現れる。
ノビーンの左右対称な音のひれとは異なり、片側へだけ長く伸びる非対称性を輪郭の価値にする。
