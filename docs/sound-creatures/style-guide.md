# おとのいきもの — アートスタイルガイド

## 状態

2026-08-04 に Issue #122 の代表キャラクターと視覚方針が人手承認された。
この初版を残り7体の制作基準とする。名前はUIへ組み込む段階まで仮称として扱う。

## 基準キャラクター

| 項目           | 内容                                                             |
| -------------- | ---------------------------------------------------------------- |
| DiscoveryId    | `interval_third`                                                 |
| 仮称           | ミッツ / Mitts                                                   |
| 性格           | 少し離れた音と一緒に歌うのが好き                                 |
| 音とのつながり | 左右の耳が2つの音、左の3節と右の4節が3度を作る3半音・4半音を表す |
| アセット       | `public/creatures/interval_third/portrait.png`                   |

ミッツは耳だけで音を聞くのではなく、2つの耳から入った音を丸い体全体で受け止める。
「音楽を知っている先生」ではなく、子どもと一緒に音を面白がる存在として描く。

## 形

### 外周

- 頭と胴を分けない、縦長の豆またはしずくに近い丸い体を基本にする。
- 左右へ大きく開いた「音の耳」を、その個体の音楽的特徴に合わせて変形する。
- ミッツの左耳は3つ、右耳は4つの大きな丸い節を持つ。
- 耳の間には背景が見える深い谷を作り、96pxのシルエットでも2つに読めるようにする。
- 手足や飾りを増やしすぎず、外周だけで性格が伝わる形を優先する。

### 顔

- 目は縦長の濃色2つを基本にし、ハイライトは各1点までとする。
- 口は小さく、喜び・驚き・好奇心を読み取れる形にする。
- 顔の情報量より、音の性質を表す身体の形を優先する。
- 鼻、眉、まつ毛などを全個体の共通記号にしない。

## 線

- 外周は濃いプラム色の、途切れない丸い線で囲む。
- 1024px原画では、おおむね18〜26pxに見える太さを基準にする。
- 内側の模様は外周より細くし、96pxで消えても意味が失われない情報に限る。
- 黒一色の硬い線、鉛筆風のかすれ、毛羽立った輪郭は使用しない。

## 色

ミッツから採った代表色を、シリーズ全体の彩度・明度の基準にする。

| 用途     | 基準色    | 役割                         |
| -------- | --------- | ---------------------------- |
| 外周・目 | `#35083A` | 輪郭を締める濃いプラム       |
| 体の主色 | `#9475CE` | 落ち着きと不思議さのある紫   |
| 体の明部 | `#A68BE4` | 上面のやわらかな光           |
| 耳の主色 | `#FD816C` | 音が入ってくる温かいコーラル |
| 顔       | `#FFE5C8` | 表情を読みやすくするクリーム |

- 1体につき主色2色と小さな補助色1色を目安にする。
- UIのテーマ色を画像背景へ焼き込まない。
- 発見済みと未発見を色だけで区別しない。
- 個体同士を単なる色違いにせず、先に外周を変える。

## 質感と光

- つやを抑えた、触れられそうなソフトトイとクレイの中間の質感にする。
- 写実的な毛、羽根、皮膚、金属、ガラスは使用しない。
- 左上からのやわらかい光を全個体で共通にする。
- 陰影は丸みを伝える2〜3段階に抑え、強いコントラストを作らない。
- キャラクター画像には床、接地影、反射、発光、背景を含めない。

## 画像仕様

- 1024 × 1024pxのRGBA PNG。
- 正方形の中に全身を収め、四辺に十分な透明余白を残す。
- 四隅は完全透明にする。
- 96pxと160pxで目、口、主色、外周を確認する。
- 未発見シルエットは別画像を作らず、portraitのalphaをCSSで単色化して使う。
- 画像生成時は単色クロマキーを使用し、透過後に色かぶりと半透明の縁を検査する。

基準アセットの検査値:

- サイズ: 1024 × 1024px
- カラーモード: RGBA
- 可視領域: `(95, 115) - (904, 908)`
- 四隅のalpha: すべて0
- 可視領域に残るクロマキー由来の緑: 0px

## 動きの方向

### 初回発見

1. 左右の耳が別々に小さく反応する。
2. 2つの耳が同時に開き、体が少しだけ上へ弾む。
3. 顔が現れ、「2つの音が一緒に聞こえた」状態で止まる。

大きく飛び回らせず、証拠として光っている2音との対応が分かる動きにする。

### 再発見

左右の耳が1回ずつ動いたあと、同時に小さく光る。編集と再生は止めない。

## 今後の個体へ引き継ぐもの

引き継ぐ:

- 丸く途切れない外周線
- 目の描き込み量
- ソフトトイとクレイの中間の質感
- 左上からの光
- 透明背景と余白
- 96pxで読める外周

個体ごとに変える:

- 体の基本形
- 耳、尾、手足など音の性質を表す部位
- 主色と補助色
- 顔の位置や口の形
- 初回・再発見時の短い動き

## 禁止事項

- 特定の既存キャラクターの輪郭、顔、配色、名称規則の模倣
- 捕獲道具、進化、強さ、属性、レア度を連想させる記号
- 現実の楽器をそのまま生き物にした形
- 武器、制服、文字、数字、ロゴ、透かし
- すべての個体に同じ顔と体を使う色違い展開
- 小さい画面でしか読めない細線や細かな模様
- 怖さ、攻撃性、勝敗を主な魅力にする表現

## 生成時に固定する要素

後続個体を生成するときは、次をプロンプトの固定条件にする。

- `polished original children's game character illustration`
- `soft 2.5D cel-shaded matte finish`
- `bold clean dark-plum outline`
- `tactile rounded forms`
- 全身、中央配置、正方形、四辺に透明余白
- 96pxで読める固有シルエット
- 1体のみ、背景・床影・文字・ロゴ・武器なし
- 既存の有名キャラクターに似せない

そのうえで、各 `DiscoveryId` の音楽的特徴だけを身体構造と動きとして差し替える。
