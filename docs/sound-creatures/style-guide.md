# おとのいきもの — アートスタイルガイド

## 状態と責務

2026-08-04に Issue #122 の代表キャラクターと視覚方針が人手承認された。
同日に Issue #124 の残り7体も一体ずつ人手承認され、全8体の画像仕様が確定した。

この文書は全個体に共通する視覚言語と画像検査の正本である。名前、性格、音との
つながり、固有の動き、alt文は [`creature-roster.md`](./creature-roster.md) を正本とし、
ここには重複して記載しない。名前はUIへ組み込む段階まで仮称として扱う。

## 基準キャラクター

`interval_third` のミッツを、線、顔の情報量、質感、光の基準にする。同じ体を
使い回すための素体ではなく、シリーズの仕上がりを比較するための基準である。

- アセット: `public/creatures/interval_third/portrait.png`
- 役割: 2つの音の距離を、左右で節の数が異なる耳として身体化する
- 人物像: 音楽を教える先生ではなく、子どもと一緒に音を面白がる存在

## 形

### 外周

- 音の性質を、耳、ひれ、足、くびれ、ひだ、輪、尾など身体そのものの構造にする。
- 個体ごとに基本形を変え、同じ素体の色違いにしない。
- 手足や飾りを増やしすぎず、96pxの単色シルエットでも個体を判別できる外周を優先する。
- 意味を持つ隙間や穴は、小さい表示でも閉じない十分な幅を確保する。
- 現実の動物、楽器、食べ物、道具をそのままキャラクター化しない。

### 顔

- 目は縦長または丸い濃色2つを基本にし、ハイライトは各1点までとする。
- 口は小さく、喜び、驚き、好奇心を読み取れる形にする。
- 顔の情報量より、音の性質を表す身体の形を優先する。
- 鼻、眉、まつ毛などを全個体の共通記号にしない。

## 線

- 外周は濃いプラム色の、途切れない丸い線で囲む。
- 1024px原画では、おおむね18〜26pxに見える太さを基準にする。
- 内側の模様は外周より細くし、96pxで消えても意味が失われない情報に限る。
- 黒一色の硬い線、鉛筆風のかすれ、毛羽立った輪郭は使用しない。

## 色

ミッツから採った色を、シリーズ全体の彩度と明度の基準にする。

| 用途     | 基準色    | 役割                         |
| -------- | --------- | ---------------------------- |
| 外周・目 | `#35083A` | 輪郭を締める濃いプラム       |
| 体の主色 | `#9475CE` | 落ち着きと不思議さのある紫   |
| 体の明部 | `#A68BE4` | 上面のやわらかな光           |
| 耳の主色 | `#FD816C` | 音が入ってくる温かいコーラル |
| 顔       | `#FFE5C8` | 表情を読みやすくするクリーム |

- 1体につき主色2色と小さな補助色1色を目安にする。
- UIのテーマ色を画像背景へ焼き込まない。
- 発見済みと未発見を色だけで区別しない。
- 個体同士を単なる色違いにせず、先に外周を変える。

## 質感と光

- つやを抑えた、触れられそうなソフトトイとクレイの中間の質感にする。
- 写実的な毛、羽根、皮膚、金属、ガラスは使用しない。
- 左上からのやわらかい光を全個体で共通にする。
- 陰影は丸みを伝える2〜3段階に抑え、強いコントラストを作らない。
- キャラクター画像には床、接地影、反射、発光、背景を含めない。

## 画像仕様

- 1024 × 1024pxのRGBA PNG。
- 正方形の中に全身を収め、四辺に十分な透明余白を残す。
- 四隅は完全透明にする。
- 96pxと160pxで目、口、主色、外周を確認する。
- 未発見シルエットは別画像を作らず、portraitのalphaをCSSで単色化して使う。
- 画像生成時は単色クロマキーを使用し、透過後に色かぶりと半透明の縁を検査する。
- 配置先は `public/creatures/<discovery-id>/portrait.png` に統一する。

## 動きの原則

### 初回発見

- 検出された音に対応する身体の部位を、実際の音の順番に反応させる。
- 大きく飛び回らせず、グリッド上で光る証拠との対応を追える範囲に抑える。
- 登場後は子どもが「わかった！」を押すまで、名前と表情を読める状態で止める。
- 個体ごとの動きは `creature-roster.md` の「初回の動き」を使う。

### 再発見

- 個体固有の部位を一度だけ短く反応させる。
- 再生や編集は止めない。
- `prefers-reduced-motion` では、移動や弾みを短いフェードまたは明度変化に置き換える。

## 禁止事項

- 特定の既存キャラクターの輪郭、顔、配色、名称規則の模倣
- 捕獲道具、進化、強さ、属性、レア度を連想させる記号
- 現実の楽器をそのまま生き物にした形
- 武器、制服、文字、数字、ロゴ、透かし
- すべての個体に同じ顔と体を使う色違い展開
- 小さい画面でしか読めない細線や細かな模様
- 怖さ、攻撃性、勝敗を主な魅力にする表現

## 新しい個体を追加する場合

1. `creature-roster.md` に個体固有の設計票を追加する。
2. 次の共通条件を固定し、音楽的特徴だけを身体構造と動きとして差し替える。
   - `polished original children's game character illustration`
   - `soft 2.5D cel-shaded matte finish`
   - `bold clean dark-plum outline`
   - `tactile rounded forms`
   - 全身、中央配置、正方形、四辺に透明余白
   - 96pxで読める固有シルエット
   - 1体のみ、背景、床影、文字、ロゴ、武器なし
   - 既存の有名キャラクターに似せない
3. 1024pxのalpha、96px、160px、単色シルエットを検査する。
4. 既存個体と並べて、輪郭、配色、顔、身体構造の重複がないことを人が確認する。
