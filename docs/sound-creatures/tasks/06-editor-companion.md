# Task 06 — 見つけた生き物を編集画面へ連れて行く

## 状態

実装完了・確認待ち。Task 05の利用確認を経て、Issue #133で実装した。

保存方針は、ログイン時は既存のプロフィール取得に相棒IDを同梱し、匿名時は
既存の匿名発見と同じタブ内だけに保存する。匿名選択はログイン後へ自動引継ぎしない。

## 目的

図鑑で出会った生き物から1体を選び、編集画面に「相棒」として居てもらう。
最初の実装では助言や自動作曲を行わず、子どもの操作に小さく反応する存在に留める。

## 事前調査

- 匿名ユーザーとログインユーザーの選択保存範囲
- `AccountProvider` と既存プロフィール保存方式
- モバイルでグリッド操作を邪魔しない配置
- 再生、停止、音符追加、Undoに対する最小限の反応
- アニメーション負荷と `prefers-reduced-motion`

## 実装要件

- 発見済みの生き物だけを選択できる。
- 「連れて行かない」を常に選べる。
- 相棒は初期位置を画面右下とし、ヘッダー、モーダル、発見演出を覆わない。
- 相棒はドラッグで操作したい場所から避けられ、画面外へ移動しない。
- 反応は評価語を使わず、正解・不正解を示さない。
- 選択保存にDB変更が必要なら、後方互換なmigration、RLS、型を同じIssueで設計する。
- 匿名時はブラウザ内だけに保存し、ログイン時の自動引継ぎは別途明示的に判断する。

## 対象外

- AIによる提案
- 音符の自動挿入
- 強さ、育成、好感度、レベル
- 行動履歴の収集

## 合格条件

- 未発見の生き物を選べない。
- 相棒の有無で作曲機能と発見判定が変わらない。
- 選択解除と保存範囲が子どもにも理解できる。
- 既存ユーザーと匿名ユーザーで後方互換性がある。
- lint、型検査、関連テスト、主要画面幅の手動確認が通る。

## 実装・確認記録

- `3813ceb`: `profiles.companion_discovery_id`を追加する後方互換migrationと、発見済みを
  DB側で検証するtriggerを追加した。既存profile取得へ同梱するため通常表示のSELECTは
  増えない。匿名選択は発見データと同じ`sessionStorage`へ保存し、自動引継ぎしない。
- `7bd93a6`: 図鑑の発見済みエントリへ選択操作と「つれていかない」を追加し、編集画面の
  グリッド外へ相棒を表示した。再生中、音符・ドラム操作、Undoには評価語を伴わない
  CSSの小さな反応だけを行う。
- `cabbdf5`: 発見と相棒で重複していた安全な`sessionStorage`取得を共通化し、未発見時に
  相棒選択操作がHTMLへ出ない回帰テストを追加した。
- `pnpm test`（17ファイル・129件）、`pnpm exec tsc --noEmit`、`pnpm lint`、
  `pnpm build`を通過し、全routeの静的生成を維持した。
- 匿名状態で発見、選択、編集画面表示、再生中表示、解除を確認した。1280px、768px、
  390pxで相棒がグリッドを覆わず、横方向のはみ出しがないことと、日英表示、
  ブラウザコンソールエラー0件を確認した。
- 2026-08-05にProduction DBへmigrationを適用した。カラム、外部キー、trigger、
  `SECURITY DEFINER`と空の`search_path`、RLSの維持を確認した。
- triggerの挙動はtransaction内で、未発見IDの拒否と発見済みIDの許可を確認し、
  `ROLLBACK`したため検証データは残していない。
- ログイン状態で選んだ相棒がアカウントへ保存され、編集画面に表示されることを
  2026-08-05に人手確認した。
- 人手確認のフィードバックを受け、相棒を通常レイアウトから右下のフローティング表示へ
  変更した。ドラッグと矢印キーで移動でき、固定ヘッダーより下の画面内に制限する。
  位置は行動データとして保存せず、ページを開き直すと右下へ戻る。
- 位置計算を純粋関数、操作を専用hook、見た目を表示componentへ分離した。18ファイル・
  132件のtest、型検査、lint、production buildを通過し、全routeの静的生成を維持した。
- デスクトップの実画面で右下の初期表示、ポインターdrag、矢印キー移動、固定ヘッダー下での
  境界制限を確認し、runtime errorがないことを確認した。
- 新しいフローティング表示の最終の人手確認は統合前ゲートとする。
